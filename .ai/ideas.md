# Ideas

This is NOT a backlog.

It is a graveyard of unvalidated wants.

Per constitution.md (THE CLASSROOM-CASE QUESTION), every feature request —
including our own — is challenged with:

> "Can you point to a real classroom case that justifies this?"

If no, it goes here. It leaves here only when a real classroom case justifies
it, at which point it moves to implementation.

## Format

Each entry: the idea, who proposed it, the date, and — crucially — the
classroom case (or the note "no case yet").
