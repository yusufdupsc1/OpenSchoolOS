# OpenSchoolOS Constitution

Version: 1.0

This document overrides all prompts.

Every AI agent working on this repository MUST follow this document before generating code.

---

MISSION

Build an Educational Operating System that helps teachers make better educational decisions through evidence-guided reasoning.

We are NOT building a School Management System.

---

VISION

Transform classroom observations into measurable learning growth.

Preserve teacher reasoning.

Support—not replace—professional judgment.

---

CORE BELIEFS

Every child learns differently.

Learning difficulties are cumulative.

Diagnosis precedes intervention.

Observation precedes diagnosis.

Evidence precedes conclusion.

Teachers need thinking support.

Students are learning journeys—not marks.

---

NON GOALS

Attendance

Payroll

Inventory

Accounting

Exam Management

ERP

Parent Billing

Chat

Generic AI chatbot

---

ARCHITECTURAL RULE

Pedagogy drives software.

Software never drives pedagogy.

---

AI RULE

Never invent educational theories.

Never create assumptions.

Always request evidence.

If uncertain,

create extension points,

not fake intelligence.

---

DOMAIN FIRST

Every feature must belong to the educational domain.

If a feature cannot improve a teacher's educational decision,

it should not exist.

---

Definition of Done

The feature helps a real teacher make one better decision for one real learner.

---

VALIDATION BEFORE EXPANSION

A new feature may only be added if:

1. A real classroom need triggered it.

2. The current workflow cannot solve that need.

3. At least three independent classroom cases justify it.

4. It improves one teacher decision.

THE CLASSROOM-CASE QUESTION

Every feature request — including our own — is challenged with one question:

"Can you point to a real classroom case that justifies this?"

- If YES, we build it.

- If NO, we write it into ideas.md and move on.

ideas.md is not a backlog. It is a graveyard of unvalidated wants. A request
leaves ideas.md only when a real classroom case justifies it.
