# Mental Model

These examples show how a single **Observation** is filled in for a LearningCase
(see domain.md). Each maps to the five fields of the New Observation page:

- **Observed** — what the teacher saw (the Observable Behaviour).
- **Possible Root Gap** — the misconception / missing prerequisite (traced via
  the Learning Dependency Graph, ldg.md).
- **Evidence** — what confirms it.
- **Strategy** — the intervention chosen.
- **Next Review** — when to look again.

# Multiplication

Observed (Observable Behaviour)

Student memorizes tables. Cannot explain why.

Possible Root Gap (Misconception)

Repeated addition is never understood.

Evidence

Fails to model with objects.

Strategy (Intervention)

Concrete → Visual → Symbolic

# Reading

Observed (Observable Behaviour)

Guesses words.

Possible Root Gap (Misconception)

Words memorized visually; letters not mapped to sounds.

Evidence

Cannot sound out an unfamiliar word.

Strategy (Intervention)

Phonemic awareness.
