# Workflow: Knowledge Update

Use when educational knowledge changes — competencies, misconceptions,
interventions, mental models, mastery criteria.

## 1. Think (A00, A10)
- What classroom case motivates this knowledge? Never invent theories.
- This is knowledge, not code. It belongs in knowledge/, not in application
  logic (see A30).

## 2. Locate (A30)
- Place the knowledge under knowledge/ (e.g. knowledge/educational-principles.md
  already exists). Source code must consume it; never hardcode it.

## 3. Model (A20)
- If the knowledge implies a domain change, route to domain-change.md instead.
- Otherwise keep it as reference content the LDG and cases consume.

## 4. Review (A70)
- Check educational consistency with philosophy.md, educational-principles.md,
  ldg.md, mental-model.md. No contradictions.

## 5. Document
- Update glossary.md if a new term is introduced. Note in decision-log.md.
