# Workflow: Research

Use when investigating before committing to a build.

## 1. Think (A00)
- Frame the educational problem first. Never start from a technology.

## 2. Research Questions (A10)
- What educational problem exists? Who experiences it? How is it observed?
  What evidence supports it? How do teachers currently solve it? Why is current
  practice insufficient? How will success be measured?
- Never continue before answering these.

## 3. Model Sketch (A20)
- Sketch entities/aggregates. For v0 that means Student, LearningCase,
  Observation — propose new ones only with a classroom case.

## 4. Knowledge Scan (A30)
- Check knowledge/ for existing competencies, misconceptions, interventions,
  mental models. Consume, don't duplicate.

## 5. Outcome
- Produce a written finding. If it justifies building, route to new-feature.md.
- If not, file the open question in research/ or ideas.md and stop.
